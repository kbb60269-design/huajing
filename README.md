# 华井 HUA JING

以敦煌宝相花纹样为灵感的东方茶器品牌网站。色彩、标志、文案与产品结构依煦《华井品牌策划与视觉应用手册》。

口号：让敦煌花韵，在一盘茶中延续。以花为纹，以器载美。

长期网址：[https://kbb60269-design.github.io/huajing/](https://kbb60269-design.github.io/huajing/)

本仓库已适配 GitHub Pages 项目站点：静态导出，`basePath` 为 `/huajing`。推送到 `main` 后，GitHub Actions 会构建并发布。咨询表单只在浏览器里校验并确认，不依赖服务器接口，也不会发信。

## 本地预览

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43117/huajing/](http://127.0.0.1:43117/huajing/)。

生产静态站点：

```bash
npm run build
npx --yes serve out
```

## 页面

- `/` 首页
- `/story` 品牌
- `/collections` 器物，以及花序、花间、花素三个系列页
- `/pattern` 宝相花纹样与标准色
- `/gift` 礼盒、小礼盒与杯垫
- `/space` 茶器空间
- `/inquire` 咨询

手册没有登记零售价、门店地址和公开信箱。咨询表单只在页面上确认你写下的意向，不会把信件发到外部。
